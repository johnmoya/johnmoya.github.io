02 Featured projects

Open source · v1.1.0 01

Local Quant Risk AI

Market Risk · Backtesting · Local LLMs

A local market-risk engine implementing Historical, Parametric and Monte Carlo VaR, Expected Shortfall and Kupiec / Christoffersen backtesting with Basel traffic-light analysis — now extended to multi-asset portfolios.

The architecture strictly separates computation from narration: a deterministic risk_engine produces results, and a local LLM (Qwen3 8B via Ollama) explains them from a structured fact sheet, guarded by numeric checks so it can never hallucinate a figure.

  • FastAPI service with single-asset and /portfolio/* endpoints
  • Real-data validation on SPY 2015–2025 — documented where Gaussian VaR under-predicts tail risk
  • CI on GitHub Actions (Python 3.11 & 3.12), semantic versioned releases
